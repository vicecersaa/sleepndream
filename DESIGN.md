# Sleep & Dream design

The storefront uses the existing navy and white navigation with a muted gray catalog surface. The product collection adds a compact white toolbar below the shared header. Active series use a filled navy pill. Filter menus use a white surface and a pale blue selection state.

On desktop the catalog has three product columns. The toolbar wraps and the catalog reduces to two columns on tablets and one on phones. Header heights use the shared CSS variables so the catalog toolbar sits under the global navigation while scrolling.
