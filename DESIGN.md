# Sleep & Dream design

The storefront uses the existing navy and white navigation with a muted gray catalog surface. The product collection adds a compact white toolbar below the shared header. Active series use a filled navy pill. Filter menus use a white surface and a pale blue selection state.

On desktop the catalog has three product columns. The toolbar wraps and the catalog reduces to two columns on tablets and one on phones. Header heights use the shared CSS variables so the catalog toolbar sits under the global navigation while scrolling.

The homepage quality and showroom sections form two flush, equal-column rows with alternating photos. On mobile, each row stacks into a single column.

The Kasur mega menu uses two link columns and a linked product photo on desktop. The mobile navigation presents the same link groups in an accordion.

The Perlengkapan Tidur mega menu uses a narrower panel with one link column and a linked bedding photo.

The Promo navigation button opens a full-image dialog over the current page. The backdrop starts below the global header.

The footer uses a two-column newsletter row followed by three navigation groups and a contact column. On phones the signup stacks and the links use two columns.

Support pages use a navy title band, alternating image and copy panels, and a shared contact strip linking to WhatsApp and the showrooms.
